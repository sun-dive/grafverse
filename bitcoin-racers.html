What just happened

Each line above is a transaction whose input was executed by Spend, the interpreter from @bsv/sdk — the same one a node uses to decide whether a spend is valid. A ✓ means the covenant accepted that move: the phase advanced legally, the driver's signature checked out, nLockTime cleared the tree, and the state written into the next output is exactly the one the script computed for itself. Anything else and the line would be red and the race would stop there.

The covenant is — of Bitcoin Script. It carries its own state in its own locking script, so each transaction is that script twice over — once in the output and once inside the preimage that authorises the spend. That is what a move costs.
